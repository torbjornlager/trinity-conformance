# Baseline assessment — 2026-10-01

This report records the evidence available when the conformance repository
was initialized. It is not a conformance certification.

## Trealla port

- Eight tests in `trealla-port/tests.pl` are documented as direct behavioural
  translations of tests from the earlier SWI suite; all eight pass.
- All 33 Trealla behavioural tests pass when run individually against a clean
  Trealla Prolog v3.12.6 build.
- The five self-contained WebSocket and protocol-vector tests pass against
  that build.
- The monolithic 33-test invocation repeatedly reached test 25 and then
  stalled before reporting test 26, although tests 26–33 pass together in a
  fresh process. This is an unresolved test-order, cleanup, or scheduling
  issue and prevents treating that invocation as a reliable suite result.

## Interpretation

The result is not “33 of 906”. The SWI suites use PlUnit, SWI modules, and
white-box implementation predicates and therefore cannot be executed
unchanged under Trealla. At this baseline:

- **8** directly translated SWI behavioural cases have passing Trealla
  equivalents;
- **33** Trealla-native behavioural checks pass in isolation;
- the number of shared profile-level conformance cases has not yet been
  established.

The next work should generalize the 20 T5 wire-level declarations into a
candidate-neutral runner, then extract public T0 and T2 behaviour.
